The CSV stores one `mm:ss` anchor per inspected slot; its `page` field describes secondary locators and limits. F03-F05 have no CSV timestamp or page locator. Frame dimensions describe the source pixels, not a scale reference. All inspected images are nonorthographic; mirroring is not established and no correction was applied.

Frame validation accepts `not_reviewed`, `reviewed_partial` and `reviewed`. It requires a known source, an explicit unconfirmed identity, a valid `mm:ss` timestamp for reviewed video, a locator for reviewed evidence, no locator for unreviewed evidence and timestamps within a known runtime. The external-only rights policy keeps restricted source frames out of the pack. It checks evidence-record integrity, not physical accuracy.


## Required metadata for each reviewed image

Record source ID, original URL, creator, timestamp or page locator, calibre marking, reference compatibility, side, orientation, image dimensions and rights status.

If dimensions are inferred, record the reference dimension, whether the image is orthographic, calibration method and uncertainty. Do not calibrate a movement from the watch's overall case size unless the reference dimension is actually in the same plane and visible.

Use `frame_origin = real_photo` or `real_video_frame` for evidence. Use `illustrative_diagram` for explanatory drawings. An AI-generated plate cannot become a disassembly source.

## Orientation protocol

1. Establish the stem direction and identifiable asymmetries.
2. Record the source's face, top direction and whether it was mirrored.
3. Keep the untouched source alongside any permitted annotation.
4. Assign project IDs only to parts actually identified.
5. Leave obscured identities unresolved.
6. Trace bridge outlines and pivot centers only after source identity and orientation are locked.

Do not mirror the calibre photograph solely to make it aesthetically fit an exterior view.

## What this document does not prescribe

This is a visual-reference collection workflow. It is not a workshop disassembly sequence, lubrication instruction or instruction to open the owner's watch.

If a watchmaker provides photos during a normal service, those can supply the missing evidence without unnecessary work on the watch.
